# FoundrAI — Autonomous Multi-Agent Executive Suite

> Replace the multidisciplinary executive team a founder hires with a coordinated roster of autonomous AI specialists working in parallel: **CEO, Research, Software Engineer, Designer, Marketing, Finance, and Legal**.

---

## 🌟 Key Features

- **Coordinated Multi-Agent Roster**: 7 specialized autonomous AI executives working in synchronization.
  - 👑 **CEO Agent**: Strategic direction, orchestration, operational mandates, and final charter ratification.
  - 🔬 **Research Agent**: Competitor benchmarking, TAM/SAM modeling, and beachhead customer segmentation.
  - ⚙️ **Software Engineer Agent**: Cloud architecture, data pipeline, and system specifications.
  - 🎨 **Designer Agent**: Visual identity, UI/UX interaction blueprint, and design tokens.
  - 📈 **Marketing Agent**: Go-to-market playbook, viral referral loops, and acquisition channels.
  - 💰 **Finance Agent**: Unit economics (ARPU, CAC, LTV), gross margin targets, and break-even modeling.
  - ⚖️ **Legal Agent**: Regulatory compliance, GDPR/CCPA safe-harbors, and IP protection frameworks.
- **Real-Time Boardroom Interface**: Live deliberation feed with reasoning chains, active status indicators, and stage progress tracking.
- **Live Startup Charter Panel**: Dynamically compiles the venture's master charter as the team deliberates.
- **Powered by Groq AI**: Ultra-fast LLM inference (`openai/gpt-oss-120b`).

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/harshitkurtakoti-sketch/foundrai.git
cd foundrai
```

### 2. Run locally
You can serve the static files with any HTTP server:

```bash
# Using npm / serve
npm run dev

# Or using Python
python -m http.server 3000
```

Open your browser at `http://localhost:3000`.

## 🛠️ Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Design System with semantic tokens & CSS Grid)
- **AI Engine**: Groq AI API (`openai/gpt-oss-120b`) with JSON Schema Structured Output
